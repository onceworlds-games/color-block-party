# Color Block Party

Run to the right color before the floor drops! A color is called, every other tile falls away, and anyone left standing on
nothing is out. Last one dancing wins. Up to 12 players; bots fill the floor to 8 so you can always play.

Move with WASD or the arrows (or the thumbstick), push with Space (the Push button on a phone).

Play it: https://onceworlds.com/play/color-block-party
